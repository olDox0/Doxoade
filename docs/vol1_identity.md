# 📄 Volume 1: Identidade e Escopo (Doxarchive)

## 1️⃣ Existência (POR QUÊ?)
1. Qual problema real Doxarchive resolve?
retenção de dados em grande quantidade, assim processando-os em sistemas pesquisaveis e consultaveis para outros sistemas. principalmente em dados gerais ou especificos em diversos campos
2. O que acontece se ele não existir?
Não existindo, acaba que os dados em outros projetos são fragmentados, ouseja cada projeto teria seu proprio DB em seu escopo especifico, o que seria desperdicio, pois acaba ocupando mais espaço e processamento que o dxarch poderia fazer muito melhor

## 2️⃣ Usuário Real (QUEM?)
3. Quem usa?
usuario que querem ter seus proprios sistemas de pesquisa particulares ou que querem usar estes dados para algum fim
4. O que o usuário mais erra hoje?
erra em desperdiçar tempo com crawler. quando deveria já ter os dados todos offiline.

## 🧠 Regra de Ouro
> **Projeto bom não é o que faz tudo. É o que sabe exatamente o que não faz.**
